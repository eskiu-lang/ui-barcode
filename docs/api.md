## `<barcode>`

`<barcode>`: codes read live from the camera, for apps on eskiu-lang/ui. A BarcodeScanner
shows the camera filling its box and hands each code it reads to its handler: the system's
own detector on iOS (AVFoundation), ML Kit's on Android (bundled, no network), the browser's
BarcodeDetector on the web. Browsers without it and the desktop have no scanner
(ScanUnavailable).

```eskiu
BarcodeScanner(Style{grow: 1}, "qr", scanning.get(), void(Barcode code) {
    if (code.status == ScanCode) { scanned.set(code.value); scanning.set(false); }
});
```

### ScanStatus

```eskiu
enum ScanStatus { ScanCode, ScanDenied, ScanUnavailable }
```

What a Barcode reports: a code was read, the user denied the camera, or there is no
camera or scanner here.

### Barcode

```eskiu
struct Barcode { int status; string format; string value; }
```

A code, or why the scanner shows nothing. `format` (one of the names below) and `value`
(the code's text) are borrowed for the handler's call: copy them to keep them.

### kBarcodeAll

```eskiu
const string kBarcodeAll = "all";
```

The formats a scanner looks for, comma separated: qr, aztec, datamatrix, pdf417, ean13, ean8,
upca, upce, code128, code39, code93, itf, codabar ("" or "all": every one).

### barcode_read

```eskiu
Barcode barcode_read(string name, *char payload)
```

A view event of the scanner as a Barcode; the strings point into `payload`, whose format
word is cut off in place. A code's payload is "FORMAT VALUE", the value the rest.

### barcode_release_handler

```eskiu
void barcode_release_handler(escaping fn(Barcode)->void handler)
```

Frees a scanner handler's closure; BarcodeScanner calls it when it replaces or drops the
handler.

### BarcodeHandler

```eskiu
struct BarcodeHandler { fn(Barcode)->void handler; }
```

The handler a BarcodeScanner holds between renders (owned: freed when the scanner goes
away).

### BarcodeScanner

```eskiu
void BarcodeScanner(Style style, string formats, bool scanning, escaping fn(Barcode)->void on_code)
```

The back camera, live, filling the box the layout gives it (cropped to it), reading the
codes of `formats` while `scanning`. `on_code` gets each code read (the same code again only
after a second and a half), or ScanDenied / ScanUnavailable when the camera cannot be shown.
The first one mounted asks for the camera permission.
